Ethereum node & validators

Validating since the Beacon Chain's genesis on 1 December 2020.

We've run our own Ethereum validators since day one of the Beacon Chain, alongside a go-ethereum archive node on our own hardware. It started with our contribution to the ETH2 Staking Launchpad in 2020 and keeps us hands-on with client releases, hard forks and the day-to-day work of keeping a validator online.

What we run

  • A go-ethereum (geth) archive node on our own hardware: Ethereum's full state history, queryable locally.
  • Prysm beacon node and validator client on the Beacon Chain, running since genesis.
  • Kept up to date through every network upgrade since 2020, including the Merge in 2022.

Cortical Mirror

A vision model inspired by the brain's visual cortex, built for a hackathon of the California Institute for Machine Consciousness.

We built Cortical Mirror for a hackathon run by the California Institute for Machine Consciousness (CIMC). It learns online from a live webcam using only local learning rules, the way predictive-coding theories describe the visual cortex, to see how far brain-like learning gets without a pre-trained network.

What we built

  • Learns motion-sensitive cells from the live video stream.
  • Finds objects and builds a scene graph of what it sees.
  • Tested on the UCF101 action-recognition video dataset.

04

ph-reactor

An experimental peer-to-peer document store in Rust.

A native Rust take on Powerhouse's document model: every change is an event, signed by its author and synced between peers without a central server.

What we built

  • Event-sourced storage with a write-ahead log and snapshots.
  • Per-field last-writer-wins merging with vector clocks.
  • Operations signed with ed25519.
  • Peer-to-peer sync over libp2p, with gossipsub plus a custom request/response protocol.
